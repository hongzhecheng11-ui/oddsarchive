오즈아카이브내정보

개인정보 처리방침

시행일: 2026년 7월 14일

오즈아카이브 운영자는 서비스 제공에 필요한 최소한의 정보만 처리하며, 베팅 내역이나 결제 정보를 수집하지 않습니다.

1. 처리하는 정보

  • Google 로그인 시 Google과 Supabase Auth가 처리하는 이메일, 이름, 프로필 사진, 사용자 UUID 및 로그인 세션
  • 사용자가 저장한 즐겨찾기 조건과 저장·수정 시각
  • 서비스 안정화를 위한 익명 화면 방문 종류, 브라우저 오류 유형, 주요 API 실패 상태 코드
  • 기기 안에만 저장되는 최근 검색과 비로그인 즐겨찾기

오즈아카이브의 즐겨찾기·운영 데이터 테이블에는 Google 이메일, 이름, 프로필 사진을 복사해 저장하지 않으며 화면에도 사용하지 않습니다. 다만 인증 제공자인 Google과 Supabase Auth에는 로그인에 필요한 계정 정보가 보관될 수 있습니다. 익명 오류 기록에는 사용자가 입력한 배당, 팀명, 사용자 ID를 포함하지 않습니다.

2. 이용 목적

  • Google 로그인 및 기기 간 즐겨찾기 동기화
  • 서비스 오류 확인과 화면 이용 현황 개선
  • 부정 접근 방지와 서비스 운영

3. 보관과 삭제

서버 즐겨찾기와 사용자 UUID는 사용자가 계정을 삭제할 때까지 보관합니다. 계정 삭제 시 인증 계정과 연결된 서버 즐겨찾기를 삭제합니다. 기기 로컬 데이터는 사용자가 브라우저 또는 앱 저장공간을 지울 때 삭제됩니다. 익명 운영 로그는 호스팅 서비스의 보존 설정에 따라 제한된 기간 동안 보관됩니다.

4. 제3자 처리 서비스

  • Supabase: 인증, 사용자 UUID 및 서버 즐겨찾기 저장
  • Google: Google OAuth 로그인
  • Vercel: 웹 호스팅, 서버 API 실행 및 익명 운영 로그
  • API-Football: 축구 경기 정보 제공. 사용자 개인정보는 전송하지 않음

5. 보호 조치

행 단위 보안(RLS)으로 로그인 사용자가 자신의 즐겨찾기에만 접근하도록 제한합니다. 서버 관리자 키와 Google Client Secret은 브라우저 및 공개 저장소에 포함하지 않습니다.

6. 이용자의 권리

내정보 화면에서 로그아웃하거나 계정과 서버 데이터를 직접 삭제할 수 있습니다. 계정 삭제 후에도 기기에 저장된 비로그인 즐겨찾기는 사용자가 직접 지우기 전까지 남을 수 있습니다.
