## Data safety 답변 초안

다음 항목은 출시 직전 실제 운영 설정과 다시 대조한다.

| 데이터 유형 | 수집 | 공유 | 목적 | 선택 여부 |
| --- | --- | --- | --- | --- |
| 이메일·이름·프로필 사진 | Google/Supabase Auth에서 처리 | 아니요 | 계정 인증 | Google 로그인 선택 시 |
| 사용자 ID(UUID) | 예 | 아니요 | 계정 관리, 즐겨찾기 동기화 | Google 로그인 선택 시 |
| 앱 상호작용(화면 종류) | 예, 익명 | 아니요 | 분석 | 자동 |
| 오류·진단 정보 | 예, 익명 | 아니요 | 앱 기능 및 진단 | 자동 |
| 즐겨찾기 | 예 | 아니요 | 앱 기능, 계정 동기화 | 사용자가 저장할 때 |

- 전송 중 암호화: 예(HTTPS)
- 계정 삭제 요청: 앱 안과 공개 웹 URL에서 모두 가능
- 판매 또는 광고 목적의 데이터 공유: 없음
- 정확한 위치, 연락처, 결제 정보, 베팅 내역: 수집하지 않음

## 콘텐츠 및 정책

- 타깃 연령은 성인 중심으로 설정한다. 배당 통계가 포함되므로 아동 대상 앱으로 표시하지 않는다.
- 실제 도박 참여, 베팅 업체 이동, 보너스·가입 유도 링크를 넣지 않는다.
- 스토어 이미지와 설명에 적중 보장, 수익 보장, 확정 추천 표현을 쓰지 않는다.
- 광고를 추가할 때는 도박·베팅 광고를 차단하고 광고 포함 여부를 Play Console에서 갱신한다.

## TWA 패키징 순서

1. 변경사항을 Vercel 운영 주소에 배포한다.
2. Chrome에서 매니페스트, 서비스 워커, 192/512 아이콘 설치 가능 여부를 확인한다.
3. PWABuilder 또는 Bubblewrap로 Trusted Web Activity 패키지를 생성한다.
4. 패키지 ID를 `com.oddsarchive.football`로 지정한다.
5. 생성된 업로드 키는 별도 백업하고 저장소에 커밋하지 않는다.
6. 인증서 SHA-256 지문으로 `/.well-known/assetlinks.json`을 생성해 배포한다.
7. Digital Asset Links 검증 후 릴리스 AAB를 만든다.
8. 내부 테스트, 비공개 테스트, 프로덕션 순으로 승격한다.

## 출시 전 수동 설정

- Vercel 서버 전용 환경변수 `SUPABASE_SERVICE_ROLE_KEY` 추가
- Supabase Auth 리디렉션 허용 URL에 운영 주소 유지
- Play App Signing 활성화 및 업로드 키 안전하게 백업
- 휴대전화·태블릿 스크린샷 등록
- 개인정보 처리방침과 계정 삭제 URL 제출
- Data safety, 콘텐츠 등급, 앱 액세스(Google 로그인은 선택 사항) 작성
